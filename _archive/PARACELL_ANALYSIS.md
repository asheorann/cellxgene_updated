# ParaCell Feature Analysis

## Summary
ParaCell extends CELLxGENE VIP with additional features for parasitology research. This document evaluates each feature for potential integration into our GutPath project.

---

## Features We Care About

### Advanced Gene Search
**What it is:** Search by gene name, product description, or GO terms (not just gene ID).

**Use case:** Biologist knows "AP2 transcription factor" but not PBANKA_1437550. Search "AP2" → find all related genes.

**How implemented:** Lookup tables stored in AnnData, parsed on page load, fuzzy search via Fuse.js library.

**Do we care?** YES - GutPath users are biologists, not bioinformaticians.

---

### Docker
**What it is:** Containerized deployment, everything is packaged together so the application can run anywhere.

**Use case:** Deploy to a server without dependency issues and maintain a reproducible environment.

**How implemented:** Dockerfile provided; image can be hosted on Docker Hub.

**Do we care?** YES - GutPath is being deployed to a Penn Vet server/AWS EC2, so Docker can simplify deployment significantly.

---

### Text File → paraCell_setup Change
**What it is:** Configuration moved from a separate .txt file into the .h5ad itself: `adata.uns['paraCell_setup']`.

**Use case:** Share one file instead of two; configuration cannot become separated from the data.

**How implemented:** Python dictionary stored in the uns slot and read on launch to determine which features activate.

**Do we care?** YES - Cleaner data management, especially if GutPath hosts multiple datasets.

---
## Features That Are Nice-to-Have

### External Database Links
**What it is:** Gene names in result tables become clickable links to VEuPathDB/NCBI.

**Use case:** Find a differentially expressed gene → one click to see full annotation, orthologs, literature, etc.

**How implemented:** Database choice stored in paraCell_setup; gene names automatically formatted as hyperlinks.

**Do we care?** MODERATE - Nice quality-of-life feature, but GutPath is mouse gut (NCBI), not parasites (VEuPathDB). Still useful.

---

### Trajectory Inference
**What it is:** Visualize developmental paths through cell states (pseudotime).

**Use case:** Stem cell → differentiated cell, parasite life-cycle stages, immune activation trajectories.

**How implemented:**
- Slingshot lineages: pre-computed and stored in AnnData.
- PAGA: computed on demand via Scanpy.
- TradeSeq: R package via rpy2 bridge for gene expression along a trajectory.

**Do we care?** MAYBE - Depends on whether GutPath has meaningful trajectories, such as gut epithelium turnover or immune-cell activation. Ask the lab.

---

## Features We Don't Need

### Host-Parasite Interaction Analysis
**What it is:** Separate host and parasite genes from dual RNA-seq and analyze them independently but linked.

**Use case:** Toxoplasma-infected macrophage → what is the parasite doing vs. how is the host responding?

**How implemented:**
- Pre-defined host_genes / parasite_genes lists in AnnData.
- Separate UMAPs generated by subsetting.
- Plotly.js lasso selection on one UMAP highlights the same cells on the other.

**Do we care?** NO - GutPath is a mouse gut atlas, not an infection study. There is no parasite component.

## Other Improvements in ParaCell

### Publication-Quality Figure Export
ParaCell allows figures to be exported in SVG, PDF, or high-resolution PNG (up to 600 DPI).

| Format | Description |
|--------|-------------|
| SVG | Vector format; scales without quality loss, editable in Illustrator/Inkscape |
| PDF | Vector format; publication-ready, embeds fonts |
| PNG (600 DPI) | High-resolution raster/bitmap image |

**Improvement over VIP:** VIP's default was lower-quality PNG. ParaCell makes it easier to directly generate figures suitable for papers/publications.

---

### Interactive Visualizations
ParaCell adds Plotly.js for interactive plots rather than relying only on static plots.

| Feature | Description |
|---------|-------------|
| Cell Population View | Interactive scatter plot; users can hover over points to see additional information such as gene annotations |
| Host-Parasite UMAPs | Users can lasso/select cells on one UMAP, and the corresponding cells are highlighted on the other UMAP |

**Improvement over VIP:** Base VIP primarily uses static Matplotlib plots, while ParaCell adds plots users can directly interact with.

---

### Interactive Result Tables
Result tables (DEG results, TradeSeq results, marker genes) use jQuery DataTables.

- Columns can be sorted
- Results can be searched/filtered
- Tables can be downloaded as CSV files

Makes it easier for researchers to explore large result sets and export results for further analysis.

---

## VIP Features to Keep (Not in ParaCell)

| Feature | Why Keep It |
|---------|-------------|
| `adata_to_df()` | Handles sparse matrices safely - prevents crashes on large datasets |
| Visium/CosMx spatial viz | Spatial transcriptomics support (future work) |
| Pandas/AnnData compat fixes | Stability with newer library versions |

---

## Decision: Build on VIP Base

We will build our cell-cell communication feature on top of **cellxgene_VIP** (not ParaCell) because:
1. VIP has critical bug fixes (sparse matrix handling)
2. VIP has spatial support we may need later
3. We can selectively port ParaCell features we need
